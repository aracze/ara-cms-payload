## Legacy Grails project (migration source)

When migrating features from the legacy Grails site or checking legacy behavior
(URLs, domain model, business rules), read
`grails/AI_MIGRATION_SOURCE.md` — a compact knowledge base
of the old `aracze-grails` project (architecture, domain model, conventions).
Note: **ten dokument je v repu** (výjimka v `.gitignore`), takže je i v čerstvém klonu.
Zbytek `grails/` — samotný legacy kód — je dál ignorovaný a leží jen na strojích, které
migrační podklady mají. Konkrétní dotazy do staré databáze najdeš ve smazaných migračních
skriptech v git historii; rozcestník je v README v sekci „Stará databáze“.
